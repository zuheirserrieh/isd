# City Explorer

Discover a city through its history, upcoming events, maps, and a built-in Q&A chatbot.

## Features

- **City search** with location lookup through OpenStreetMap (Nominatim)
- **History summaries** pulled from Wikipedia
- **Upcoming events** from the Ticketmaster Discovery API
- **Maps** of the selected city
- **Chatbot** for quick questions about the city

## Tech stack

Vue 3 · JavaScript · PHP · HTML · CSS

## Getting started

1. Copy `.env.example` to `.env` and add your Ticketmaster API key.
2. Start a local PHP server from the project folder:

```bash
php -S localhost:8000
```

3. Open http://localhost:8000.
